# xChat Trading Platform — Traceability Matrix

Status: final (Phases 0-16 complete)

Each in-scope requirement must eventually be traceable to the migration, RPC/API, TypeScript,
UI and test artefacts that implement it. During Phase 1 all implementation columns are `planned`;
they are filled as the corresponding phase completes. A requirement is `done` only when every
planned artefact column is filled and its tests pass.

Columns:

- Requirement — stable ID from docs/trading/requirements.md
- Migration — timestamped migration(s) that implement the schema/RPC
- RPC/API — Supabase RPC / OpenAPI use case
- TypeScript — repositories, schemas, services, hooks
- UI — components/pages
- Tests — pgTAP / unit / contract / integration / Playwright
- Status — `planned` | `in_progress` | `done` | `blocked`

Phase 3 note: the 14 main zod schemas (7 RFQ + 7 quotation) and their generated
JSON Schemas (`docs/api/schemas/`) are complete and unit-tested. The `TypeScript`
column references `src/schemas/` where the schema artefact exists; remaining
migration/RPC/UI columns are filled as Phases 4-7 land.
